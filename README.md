# Student Performance Analyzer

A beginner-friendly Python project for analyzing student marks using **Pandas**, **NumPy**, and **Matplotlib**.

## 📌 Features

* Load student data from a CSV file
* Calculate total marks
* Calculate average marks
* Determine Pass/Fail results
* Assign grades
* Find the top student
* Find students who need improvement
* Calculate subject-wise averages
* Analyze Python marks using NumPy
* Compare Pandas and NumPy calculations
* Find the top 5 students
* Visualize student performance using charts

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

```bash
cd student-performance-analyzer
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the program

```bash
python main.py
```
